# NXTQR — Smart QR Infrastructure

**Intelligence behind every scan.**

Create once. Change anytime. Route intelligently. Measure everything.

NXTQR is a premium Smart QR Infrastructure and campaign-management SaaS platform engineered for creators, modern businesses, agencies, developers, and enterprise teams.

---

## Official Product Suite

- **NXTQR Studio**: Flagship 3-column QR creation, pixel styling, eye styling, brand frames, and vector export (SVG, PDF, PNG) with real-time scanability telemetry.
- **NXTQR Routes**: Context-aware traffic routing engine. Route every scan based on country, device, OS, time of day, language, or campaign rules with automated fallback destinations.
- **NXTQR Analytics**: Post-scan intelligence, audience insights, technology breakdown, geography distribution, hour-of-day heatmap, and conversion funnel tracking.
- **NXTQR Guardian**: 24/7 autonomous destination monitoring, edge latency tracking, and broken link incident recovery across all published QR endpoints.
- **NXTQR Teams**: Organization and workspace management, role-based access control (RBAC), multi-step approval workflows, and audit logging.
- **NXTQR Developers**: Programmatic QR generation, destination updates, webhook events, and API key management powered by Cloudflare edge infrastructure.

## Visual Identity & Design System

- **Brand Symbol**: Continuous intelligent route forming the geometric structure of an "N" (`SOURCE` $\rightarrow$ `ROUTE` $\rightarrow$ `INTELLIGENCE` $\rightarrow$ `DESTINATION`).
- **Signature NXTQR Pixel Spectrum**: Warm modular QR spectrum band (`#CC3A05` $\rightarrow$ `#FA520F` $\rightarrow$ `#FFA110` $\rightarrow$ `#FFD900` $\rightarrow$ `#FFF8E0`).
- **Color System**: Primary Orange (`#FA520F`), Deep Orange (`#CC3A05`), Warm Cream surfaces (`#FFF8E0`), Beige borders (`#E6D5A8`), and semantic Dark Mode (`#111111`–`#151515`).
- **Typography**: `Cormorant Garamond` serif displays paired with `Inter` UI and `JetBrains Mono` code surfaces.
- **Microinteractions**: Fast, non-blocking page transition routing pulse (280ms) and route-motion loaders adhering to `prefers-reduced-motion`.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router + Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 + Semantic Brand Tokens
- **Themes**: `next-themes` (Light, Dark, and System modes)
- **Icons**: Lucide React & `@hugeicons/react`
- **Primitives**: Radix UI
- **Payments**: Cashfree Integration (Preserved)
